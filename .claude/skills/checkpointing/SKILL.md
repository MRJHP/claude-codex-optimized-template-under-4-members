# checkpointing

## 세션 지속화

긴 작업 중간에 컨텍스트가 끊기거나(대화 요약, 새 세션 시작) 사용자가 나중에 이어서 하고 싶어 할 때:

1. 지금까지 **완료한 것**, **진행 중인 것**, **남은 것**을 3줄 이내로 요약한다.
2. 다음 세션이 참고할 수 있도록 관련 파일/커밋/PR 링크를 함께 남긴다.
3. 아키텍처 관련 결정이 있었다면 [DESIGN.md](../../docs/DESIGN.md)에 반영한다 ([update-design 스킬](../update-design/SKILL.md)).
4. 임시 메모는 파일로 남기지 말고 대화 응답에만 포함한다 (불필요한 문서 파일을 만들지 않는다).

## 스킬 추출

같은 작업 절차를 이번 세션에서 2회 이상 반복했다면, 그 절차를 별도 스킬로 추출할지 사용자에게 제안한다.

체크리스트:
- [ ] 절차가 이 프로젝트에서 재사용될 가능성이 있는가 (일회성 작업이면 추출하지 않는다)
- [ ] `.claude/skills/<name>/SKILL.md`에 frontmatter(name, description)와 단계별 절차를 작성했는가
- [ ] description에 "언제 이 스킬을 써야 하는지" 트리거 문구를 포함했는가
