# update-lib-docs

프로젝트가 실제로 사용 중인 라이브러리에 대한 요약을 [.claude/docs/libraries/](../../docs/libraries/)에 유지해서,
매번 공식 문서를 다시 찾지 않아도 되게 한다. (조사 자체는 [research-lib 스킬](../research-lib/SKILL.md) 사용.)

## 언제 갱신하나

- `uv add`로 새 런타임 의존성을 추가했을 때
- 기존 라이브러리를 메이저 버전 업그레이드했을 때
- 프로젝트에서 그 라이브러리를 쓰는 방식에 대한 내부 컨벤션이 생겼을 때

## 문서 형식

`.claude/docs/libraries/<라이브러리명>.md`:

```markdown
# <라이브러리명> (버전 X.Y)

## 이 프로젝트에서 쓰는 목적
...

## 핵심 사용 패턴
```python
# 이 프로젝트에서 실제로 쓰는 방식의 최소 예시
```

## 주의사항 / 흔한 함정
- ...

## 참고 링크
- 공식 문서: <URL>
```

## 원칙

- 라이브러리 공식 문서를 통째로 복사하지 않는다. **이 프로젝트에서 실제로 쓰는 부분**만 요약한다.
- 버전이 바뀌어 내용이 달라지면 문서 상단의 버전 표기를 갱신한다.
