# research-lib

Gemini CLI 없이, Claude의 WebSearch만으로 라이브러리를 조사하는 절차.

## 절차

1. **질문 명확화**: 무엇을 위한 라이브러리인지, 제약(언어 버전, 라이선스, 유지보수 활발도 등)을 확인한다.
2. **WebSearch로 후보 조사**: 공식 문서, 최근 릴리스, GitHub star/이슈 활동, 대안 비교 글을 찾는다.
3. **비교표 작성**: 후보 2~3개를 기준(기능, 성숙도, 유지보수 상태, 라이선스, 학습 곡선)으로 비교한다.
4. **결과 기록**: [.claude/docs/research/](../../docs/research/)에 `<주제>.md` 파일로 저장한다.
   ```markdown
   # <라이브러리/주제> 조사 (YYYY-MM-DD)

   ## 요구사항
   ...
   ## 후보 비교
   | 후보 | 장점 | 단점 |
   |---|---|---|
   ## 결론 및 추천
   ...
   ## 출처
   - <URL>
   ```
5. **채택 시 DESIGN.md 반영**: 실제로 채택하면 [design-tracker](../design-tracker/SKILL.md) 기준에 따라
   DESIGN.md의 ADR에도 근거를 남긴다.

## 주의

- 출처 URL을 반드시 남긴다. 최신성이 중요한 정보(버전, 유지보수 상태)는 검색 시점을 명시한다.
- 확신이 없는 내용은 "~로 보인다" 식으로 표현하고, 사용자가 직접 확인해야 할 부분은 명시한다.
