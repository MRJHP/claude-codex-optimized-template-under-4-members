# 언어 설정

- **사고(추론)는 영어로, 응답은 한국어로.** 내부 계획 수립·코드 분석 등은 영어 개념/용어를 그대로 활용해도 되지만,
  사용자에게 보여지는 모든 응답은 한국어로 작성한다.
- 코드 식별자(변수명, 함수명, 클래스명), 커밋 메시지, 로그 문자열은 원래 관례(보통 영어)를 따른다. 억지로 한국어로
  번역하지 않는다.
- 기술 용어(예: dependency injection, race condition)는 필요하면 원문을 그대로 쓰고, 처음 등장할 때만 간단히
  한국어 설명을 덧붙인다.
- Codex에게 위임하는 프롬프트는 영어/한국어 상관없이 명확성을 우선한다. 다만 Codex의 답변을 사용자에게 전달할 때는
  핵심을 한국어로 요약한다.
